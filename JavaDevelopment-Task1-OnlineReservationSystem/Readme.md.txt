# Online Reservation System

## Overview

The Online Reservation System is a Java-based application developed as part of the Oasis Infobyte Java Development Internship.

The system allows users to perform reservation-related operations through a simple and user-friendly interface.

## Features

* User login
* Reservation/booking functionality
* Train or reservation details
* Ticket/reservation information
* Cancellation functionality
* User-friendly interface

## Technologies Used

* Java
* Maven
* Object-Oriented Programming
* Java Swing / Console Interface
* Git and GitHub

## Project Structure

OnlineReservationSystem/
├── src/
├── pom.xml
├── README.md
└── screenshots/

## How to Run

1. Install Java JDK.
2. Make sure Maven is installed.
3. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
4. Build the Maven project.
5. Run the main Java class.
